# binayakpurohit.github.io

Personal portfolio of **Binayak Purohit** — Software Engineer II at Worksoft (.NET, C#, AI agents & MCP).

Live at **https://binayakpurohit.github.io/**

- Plain HTML / CSS / JS — no build step; GitHub Pages serves `main` directly.
- `index.html` — content · `assets/css/styles.css` — styles (dark/light theme) · `assets/js/main.js` — nav, theme toggle, scroll reveals, typing effect.
- Preview locally: `python -m http.server 8000` then open http://localhost:8000.

Photos are from [Unsplash](https://unsplash.com) (free to use under the Unsplash License); photographers are credited in the site footer.
